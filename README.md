# 🕵️‍♂️ EarthTrend Detective

Official repository for the **2026 NASA International Space Apps Challenge** (**Vilhena, Rondônia, Brazil**), competing in the **`Be An Earth System Trend Detective!`** challenge.

---

## 🎯 Overview
**EarthTrend Detective** is an interactive climate and environmental forensics platform. It enables researchers, farmers, students, and decision-makers to investigate any location on Earth using decades of open NASA satellite and climatology data, determining:
1. **What** is changing? *(Temperature, precipitation, soil moisture, aerosols)*
2. **Where** is it changing? *(Interactive map + regional case dossiers for Rondônia & Brazil)*
3. **By how much?** *(Annual/decadal rate of change via Sen's Slope Estimator)*
4. **Is it statistically significant?** *(Non-parametric Mann-Kendall trend test with Z-score and p-value)*

---

## 🛰️ NASA Open Data Sources
- **[NASA POWER API](https://power.larc.nasa.gov/):** Daily and monthly agroclimatology time series (1981–2026).
- **[NASA GISTEMP](https://data.giss.nasa.gov/gistemp/):** Long-term surface temperature anomaly records.
- **[NASA SMAP](https://smap.jpl.nasa.gov/):** Surface and root-zone soil moisture datasets.
- **[NASA FIRMS / MODIS](https://firms.modaps.eosdis.nasa.gov/):** Active thermal anomalies and aerosol trends.
